## Launch fix (iOS / macOS "not opening")

- [x] Root cause: `main()` threw in `checkEnv` before `runApp` whenever the app started without
  `--dart-define-from-file` (Xcode Run, editor Run, plain `flutter run`). The window/launch screen stayed blank.
  Now `main()` shows `ConfigErrorApp` with the fix instead (`lib/core/ui/config_error_app.dart`).
- [x] `.vscode/launch.json` passes `--dart-define-from-file` (Cursor/VS Code Run works).
- [x] macOS sandbox lacked `com.apple.security.network.client` → no network. Added (Debug + Release), plus
  `device.audio-input` and `files.user-selected.read-only`.
- [x] Visible app name is "Relay" on macOS (`PRODUCT_NAME`), iOS, Android and web.

## Database — `supabase/migrations/20261007000001_chat.sql`

- [x] RPCs: `get_or_create_dm` (advisory-locked, idempotent), `create_group`, `set_member_role`, `mark_read`
  (monotonic), `get_conversation_list` (last message, unread count, DM peer), `create_invite` (reuses the active link),
  `revoke_invites`, `get_invite` (preview), `join_via_invite`.
- [x] `conversation_invites` table (admin-readable only; no client writes).
- [x] Last-admin rule: when a group loses its last admin, the longest-standing member is promoted (trigger).
  `set_member_role` refuses to demote the last admin.
- [x] Soft delete scrubs body + attachment columns and drops reactions; deleting doesn't stamp `edited_at`.
- [x] `messages.attachment_path` must start with `{conversation_id}/` (check constraint).
- [x] Realtime publication: messages, message_reactions, conversation_members, conversations.
- [x] Storage: private `attachments` (members only, checked on the object path; 50 MB), public `avatars`
  (owner writes `{uid}/…`; 5 MB).
- [x] Blank `""` username in signup metadata falls back to `user_<id>`.
- [x] Grants follow the M1 revoke pattern.
- [x] pgTAP: `supabase/tests/03_chat_test.sql` (43 tests).

## App

- [x] Data: `ConversationRepository`, `MessageRepository` (pages of 50, keyset on `created_at`; idempotent send by
  client UUID; upload then insert; signed URLs cached ~50 min; realtime `watch`), `PeopleRepository`,
  `PresenceService` (global presence channel `online`, broadcast typing per conversation, connection state).
  Errors map to readable `AppFailure`s (`lib/core/app_failure.dart`).
- [x] `ConversationListController` (realtime → debounced refetch), `ChatController` (optimistic send with
  `sending/failed` + retry, paging, realtime merge, reactions, edit/delete, typing, debounced `mark_read` only while
  the app is in front).
- [x] Screens: chat list (search, All/Unread/Groups/Direct, skeleton, empty, error, offline banner), chat
  (bubbles with grouped corners, sender names/avatars in groups, date + "New" dividers, reply quotes, reactions,
  ✓ / ✓✓ + "Seen"/"Seen by N", typing dots + "X is typing…", jump-to-latest, failed → retry), composer (attach
  menu: photo / camera on phones / file; voice notes with live waveform; Enter sends on desktop/web), actions sheet
  (react, reply, copy, edit, delete, retry), image viewer, file card, voice player, People, New chat, New group,
  Add people, Group info (rename, invite link create/copy/reset, roles, remove, leave), Join invite, 404.
- [x] Adaptive layout: ≥840px → black nav rail + 340px list + chat pane; phones → bottom bar (Chats, People).
- [x] Profile: avatar upload; last-seen stamped on background / sign-out.
- [x] Invite links: `APP_URL/#/join/<token>` (`APP_URL` in the env file, default `http://localhost:3000`). Opening one
  while signed out resumes after sign-in. On phones, paste a link in New chat → "Join with a link".
- [x] Theme: M3 surface/outline roles + dialog, sheet, menu, snackbar, chip, nav, checkbox themes.
